Frequently asked questions

The short answers. The rest you'll discover in seconds.

Do I need Spotify Premium?

No. OmniDL reads a playlist's track list from Spotify's public page — no login, no developer app, no Premium. It then fetches each track's official audio from YouTube Music, so you get the studio version without a subscription.

Can I download video, not just audio?

Yes. Flip the Audio / Video toggle and OmniDL grabs the full video as an MP4 — up to 4K, using H.264/AAC so it plays in every player. Prefer the highest-quality codecs? Switch the container to MKV in Settings.

What audio quality and formats do I get?

By default OmniDL keeps the native opus stream (no quality-losing re-encode, ~half the size of a 320k MP3). You can switch to m4a, mp3, flac and more in Settings. Every file gets correct title, artist, album, track number and cover art. For video, choose MP4 (most compatible) or MKV, up to 4K.

Can it handle big playlists?

Yes — it pages through the full track list (100+ tracks) and downloads several at once, each with its own live progress line. Tracks already in your folder are skipped, so you can re-run a playlist to grab only what's missing.

Is this legal?

OmniDL is a general-purpose tool for personal use — backing up music you have the right to. You're responsible for complying with the terms of the services you use and copyright law. Please support the artists you love. See our Terms.

Where do my downloads go?

When you start a download, OmniDL fetches the media and your browser saves the file like any other download. It's a hosted service, so requests are processed on our servers; there are no accounts, and we only keep standard server logs and basic analytics to run the site. See our Privacy page for details.
